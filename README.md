# Local Legal Data

Open data about U.S. law firms and local legal topics, published as plain files anyone can read, cite or download.

## What is here

- [Law firm directory](firms/README.md): 259 firms with practice areas, offices, attorneys and public profiles
- [firms.csv](data/firms.csv) and [firms.json](data/firms.json): the same directory as a dataset

## Sources and updates

Firm details are summarized from each firm's own website and public profiles. County assignments come from the U.S. Census Bureau geocoder. Crash figures come from the NHTSA Fatality Analysis Reporting System. The files are rebuilt automatically every month.

Firm data last updated 2026-11-10.

## Use

The crash figures are U.S. government data in the public domain. The compiled files in this repository may be reused with a link back to this page.

Firms listed here are clients of MileMark Legal Marketing, which maintains this dataset.
